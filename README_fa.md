| ویژگی | توضیح |

## ⚡ راه‌اندازی سریع (محیط توسعه)

**پیش‌نیازها**  
پایتون 3.10+، Node 18+، npm یا yarn

### 🔧 بک‌اند

```bash
cd backend

# ایجاد و فعال‌سازی محیط مجازی
python -m venv .venv
source .venv/bin/activate        # در ویندوز: .venv\Scripts\activate

# نصب وابستگی‌ها
pip install -r requirements.txt

# تنظیم متغیر برنامه Flask
export FLASK_APP=app             # در PowerShell ویندوز: $env:FLASK_APP = 'app'

# اعمال مهاجرت‌ها (پایگاه داده SQLite در backend/anki.db ساخته می‌شود)
flask db upgrade

# اجرای سرور
flask run --port 5000            # یا: gunicorn -w 1 "app:create_app()"
```

> **تنظیمات محیطی**  
> برنامه به‌طور پیش‌فرض از SQLite استفاده می‌کند. برای تغییر، متغیر `SQLALCHEMY_DATABASE_URI` را در تنظیمات instance یا به‌عنوان متغیر محیطی پیش از اجرای Flask تنظیم کنید.

### 🖥️ فرانت‌اند

```bash
cd frontend

npm install          # نصب بسته‌ها
npm run dev          # سرور توسعه Vite → معمولاً http://localhost:5173
npm test             # اجرای تست‌های واحد فرانت‌اند (Vitest)
```

### 🔗 اجرای کامل برنامه

هر دو سرور را اجرا کنید. فرانت‌اند (پورت 5173) درخواست‌های API را به `/api` می‌فرستد (CORS برای توسعه فعال است).

## 🌐 نمای کلی API

| مسیر | متد | توضیح |
|------|------|--------|
| `/api/cards?project_id=:id` | GET | دریافت کارت‌های حذف‌نشده یک پروژه |
| `/api/cards` | POST | ایجاد کارت `{ fields, tags, deck_id?, template_id? }` |
| `/api/cards/:id` | PUT | به‌روزرسانی کارت |
| `/api/cards/:id` | DELETE | حذف نرم کارت |
| `/api/cards/batch-delete` | POST | حذف نرم گروهی `{ ids: [...] }` |
| `/api/cards/restore` | POST | بازگردانی کارت‌های حذف‌شده `{ ids: [...] }` |
| `/api/cards/permanent-delete` | POST | حذف دائمی `{ ids: [...] }` |
| `/api/templates` | GET | لیست همه قالب‌ها |
| `/api/templates` | POST | ایجاد قالب |
| `/api/templates/:id` | PUT | ویرایش قالب |
| `/api/imports/upload` | POST | بارگذاری CSV → برگرداندن ستون‌ها و نمونه |
| `/api/imports/apply` | POST | اعمال سطرهای نگاشت‌شده برای ساخت کارت |
| `/api/export/json` | POST | خروجی JSON کارت‌های انتخابی |
| `/api/export/apkg` | POST | خروجی `.apkg` برای یک پروژه یا شناسه‌های کارت |
| `/api/preview` | POST | پیش‌نمایش زنده برای یک قالب + فیلدها |

## 🌍 بین‌المللی‌سازی و راست‌به‌چپ

- رشته‌های رابط کاربری در `frontend/src/i18n.js` قرار دارند. زبان‌های پشتیبانی‌شده: `en`, `fa`, `ar`.
- تغییر زبان، `document.documentElement.dir` را به `ltr` یا `rtl` تنظیم می‌کند.
- ویرایشگرهای کد (HTML/CSS) همیشه چپ‌به‌راست باقی می‌مانند تا کد در محیط‌های RTL خوانا بماند.

## 🧪 تست‌ها

```bash
# بک‌اند
cd backend && pytest

# فرانت‌اند
cd frontend && npm test
```

- تست‌های فرانت‌اند در `jsdom` اجرا می‌شوند. ماژول i18n برای جلوگیری از خطاهای jsdom، دسترسی به `window.localStorage` را محافظت می‌کند.
- Vite ممکن است یک اخطار `ExperimentalWarning` درباره `localStorage` نشان دهد که بی‌خطر است.

## 🔧 نکات و رفع اشکال

- پایگاه داده SQLite پس از اولین مهاجرت در `backend/anki.db` ایجاد می‌شود.
- در صورت شکست خروجی `.apkg`، مطمئن شوید `genanki` نصب است و مسیر `/tmp` قابل نوشتن می‌باشد (مسیر پیش‌فرض).
- بک‌اند در اولین اجرا قالب‌های پیش‌فرض و یک پروژه آزمایشی ایجاد می‌کند.
